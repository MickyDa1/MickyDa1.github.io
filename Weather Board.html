Matrix Portal Weather Board

Welcome to my **Matrix Portal Weather Board** project. This application displays live weather information for a specified location using a Matrix Portal S3 and an LED matrix display.

Developing this project significantly improved my understanding of working with APIs, particularly retrieving, processing, and displaying real-time weather data. It also introduced me to a new microcontroller platform, the Matrix Portal S3, allowing me to expand my experience beyond the Arduino and ESP32 ecosystems.

This project challenged both my patience and problem-solving skills. During development, progress came to a complete halt due to a hardware issue where the display's input pins were incorrectly aligned, preventing the system from functioning as expected. Diagnosing and resolving this issue required careful troubleshooting and perseverance, ultimately reinforcing the importance of systematic debugging when working with embedded hardware.

Overall, this project strengthened my knowledge of APIs, embedded programming, and hardware integration while providing valuable experience overcoming real-world development challenges.


After Thoughts

I found this project particularly rewarding because it presented a number of technical challenges that required persistence and creative problem-solving. After successfully resolving the hardware issues and getting the display operational, I began refining the user interface and evaluating how information should be presented on the LED matrix.

My original design included displaying the location's latitude and longitude alongside the weather data. However, during testing I found that the available display space was too limited to present this information clearly. I considered reducing the text size, but this was not a practical solution due to time constraints and the need to return to Manchester. As an alternative, I explored redesigning the interface, including the possibility of expanding the display by adding a second LED matrix. Although this feature was not implemented, the experience highlighted the importance of balancing functionality with usability and hardware limitations during the design process.
