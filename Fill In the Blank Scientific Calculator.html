Fill In the Blank Scientific Calculator

This application is designed to solve a selection of mathematical equations by calculating missing values based on the information provided by the user.

Developing this project significantly strengthened my understanding of recursion and gave me the opportunity to improve several core software engineering skills that I felt needed further development as a second-year Software Engineering student. In addition to implementing the application's functionality, I gained valuable experience using branches on Git (as this was a weakness of mine), implementing robust error handling, and producing a clear worklog, particularly through the project's README.

This was primarily an independent project, allowing me to take ownership of the design, implementation, testing, and documentation. Although I received some assistance from a classmate when researching specific equations—most notably the Azimuth calculation—the development work was completed independently. I am particularly proud of this project because it demonstrates not only my programming ability but also my commitment to following good software engineering practices throughout the development process.

Below, you will find the project's documentation, which records my day-to-day progress, including development dates, completed tasks, and the Git branches used throughout the project.


Fill In the Blank Scientific Calculator

The following areas were some of the most challenging aspects of this project, requiring me to develop my coding, research, and mathematical skills. While each topic provided valuable opportunities for further exploration, I had to maintain a strong focus on implementation, as several components required a high level of precision in order to function correctly.

  • Git Branching

    • This project provided valuable experience with Git, including creating, pulling, pushing, and merging branches. Managing different branches helped me better understand version control practices and how they support organised software development.

  • Recursion

    • Recursion was one of the most interesting concepts I explored during this project. Understanding how functions could repeatedly call themselves and correctly return calculated values required careful planning and testing, but ultimately strengthened my understanding of this programming technique.

  • Template Usage

    • I also explored the use of templates within the project, where I created a reusable base structure for the application interface and built additional elements on top of it. This improved the organisation and maintainability of the code while allowing for easier future expansion.
