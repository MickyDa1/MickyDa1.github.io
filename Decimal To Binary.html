Decimal to Binary Converter using an Arduino Uno R3

This project was my first experience developing with an Arduino Uno R3 microcontroller, where I created a simple decimal-to-binary converter. Although the project itself was relatively straightforward, it provided an excellent introduction to programming, embedded systems, and basic electronics

Throughout the project, I gained hands-on experience using the Arduino Serial library to send and receive data, as well as the `digitalWrite()` function to control LEDs and the `delay()` function to implement simple timing mechanisms. These concepts formed a strong foundation for my understanding of microcontroller programming and hardware interaction.

This was also my first project as part of the Software Engineering Team at Liverpool John Moores University. It gave me the opportunity to explore collaborative software development and confirmed my enthusiasm for working within the team. Since then, I have remained an active member and have continued to develop my technical and professional skills through a range of projects.

In addition, this project marked my introduction to Git and version control. With guidance from a senior student, I learned how to set up a Git repository and use Git for managing source code, an essential skill that has become a fundamental part of my software development workflow.


Why This project

This project was chosen because it provided a simple yet effective introduction to programming and microcontroller development while being achievable within a relatively short timeframe. It closely complemented my studies and allowed me to apply theoretical concepts in a practical setting.

In addition to developing my programming skills, the project significantly improved my understanding of binary representation, a topic I had initially found challenging. By implementing a decimal-to-binary converter, I was able to reinforce these concepts through hands-on experience, making the underlying principles much easier to understand.
