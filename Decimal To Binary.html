Decimal to Binary Converter using an Arduino Uno R3

hello and welcome to my first project, this was a simple decimal to binary converter that I created using an Arduino Uno R3 microcontroller, this project was a simple one but it helped me to learn the basics of programming and working with microcontrollers. I found this project to be really interesting as it was my first time working with a microcontroller and it was a great way to learn about the basics of programming and electronics. This also helped me understand how to use the Serial library to send data to the Arduino and how to use the digitalWrite function to control the LEDs. I also learned how to use the delay function to create a simple timing mechanism for the LEDs. This was my first project I developed with the Software Engineering Team at Liverpool John Moores University, and it was a great way to see if I was keen and interested in the team, and I am glad to say that I was and I have been a part of the team ever since. This was also the very first time I had been introduced to GIT as one of the Students in the higher level of the course showed me how to set one up and use it.
