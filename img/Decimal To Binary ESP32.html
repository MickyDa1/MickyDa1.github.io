Decimal to Binary Converter using an ESP32

This project was a simple decimal to binary converter that I created using an ESP32 microcontroller, this project was a simple one but it helped me to re-enforce my understanding of the basics of programming and working with microcontrollers. I found this project to be really interesting as it was my second time working with a microcontroller and it was a great way to learn about the basics of programming and electronics when it came to wireless communication. This also helped me understand how to use the WiFi library to connect to the internet, as well as sending the data to the ESP32 using a simple HTML page.


Challenges along the way

I found that since this was an extenstion of my first project, I found that I had a good understanding of the basics of programming and working with microcontrollers, however I found that I had to learn how to use the WiFi library to connect to the internet, since i wanted to be able to use the simple circuit I made without needing to be connected physically to the computer. This was the main challenge as I had never used the ESP32 before, or even that a microcontroller could connect to the internet.
