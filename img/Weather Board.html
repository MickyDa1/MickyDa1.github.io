Matrix Portal Weather Board

Hello and Welcome to my Matrix Portal Weather Board project, With this you should be able to see the current weather in a specific location. I found that the software I developed not only helped me to understnad the concept of APIs alot better but also helped me to learn a new type of microcontroller (Matrix Portal S3), This was a project that tested my patientce and determination as at one stage of the project I had completely halted progress due to a problem with the board that resulted with input pins NOT being aligned.


After Thoughts

I found this project to be really interesting as I went through alot of different challenges that I overcame, however once I had gotten the board working, i found that my original idea of including the longitude and latitude was not suitable for this type of project as it was too long. This meant that I would either have to make the text smaller which was not viable to do due to my return to Manchester, or I would have to change the design which could have included adding another board.
