Decimal to Binary Converter using an ESP32

This project was a wireless adaptation of my original decimal-to-binary converter, developed using an ESP32 microcontroller. While the project itself was relatively simple, it reinforced my understanding of programming fundamentals and embedded systems while introducing me to wireless communication and IoT concepts.

As this was my second project involving a microcontroller, I was able to build upon the knowledge gained from my previous Arduino-based implementation. The transition to the ESP32 allowed me to explore its built-in Wi-Fi capabilities and gain practical experience with network-connected devices.

Throughout the project, I learned how to use the "WiFi.h" library to connect the ESP32 to a wireless network and developed a simple HTML-based web interface to send data to the microcontroller remotely. This provided valuable insight into how embedded devices can interact with web technologies, strengthening my understanding of client-server communication and the development of Internet of Things (IoT) applications.


Challenges along the way

As this project was an extension of my first project, I already had a solid understanding of the fundamentals of programming and working with microcontrollers. The primary challenge was learning how to use the ESP32's built-in Wi-Fi capabilities to enable wireless communication.

My goal was to control the circuit remotely without requiring a physical connection to a computer. To achieve this, I learned how to use the `WiFi.h` library to connect the ESP32 to a wireless network and communicate with it through a simple web interface. This was my first experience working with the ESP32, and I found it fascinating to discover how a microcontroller could host a web server and interact with devices over a network.

This project significantly expanded my knowledge of embedded systems and IoT development while building on the skills I had gained from my previous Arduino-based project.
